# fake_news_detection_project


A Machine Learning-based Fake News Detection Web Application developed using Python, Flask, Bootstrap 5, and MySQL. The system classifies news articles as Fake or True using TF-IDF text vectorization and three machine learning algorithms: Logistic Regression, Linear SVM, and Random Forest.

The application includes an admin login system, interactive dashboard, dataset information, news prediction, model performance comparison, and prediction history. It also provides evaluation metrics such as Accuracy, Precision, Recall, and F1-Score.

**Technologies Used:** Python, Flask, MySQL, Bootstrap 5, HTML, CSS, JavaScript, Pandas, Scikit-learn, TF-IDF, and Chart.js.

**Dataset:** Fake.csv and True.csv (Kaggle Fake and Real News Dataset).
